# I კლასის მათემატიკა — AI Studio

ეს არის Vite + React პროექტი.

გასაშვებად:
```bash
npm install
npm run dev
```

მთავარი entry არის `index.html -> /src/main.tsx`.

4 ზედა ველი:
1. მარჯვნივ და მარცხნივ
2. ზევით და ქვევით
3. ვისწავლოთ შედარება — ბურთები, რიცხვების გარეშე
4. ვისწავლოთ შედარება, დავითვალოთ — ვაშლი 4, მსხალი 2, ბეჰემოტის დახმარებით

მაღალი ხარისხის PNG რესურსები ინახება `src/assets/comparison/`-ში.
