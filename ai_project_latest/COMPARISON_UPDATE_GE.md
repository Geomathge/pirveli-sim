# „ვისწავლოთ შედარება“ — განახლება

განახლებულია მესამე გაკვეთილი და ეწოდება **„ვისწავლოთ შედარება“**.

## დამატებულია
- მაღალი ხარისხის გამჭვირვალე PNG რესურსები: ვაშლი, მსხალი, კალამი, რვეული, ნიანგი ორივე მიმართულებით, ბეგემოტი ორივე მიმართულებით.
- `comparison-source/src/components/ComparisonLesson.tsx`
- ორი ეტაპი: **1. ნიმუში** და **2. მე ვცდი**.
- ორი წყვილი: **ვაშლი–მსხალი** და **რვეული–კალამი**.
- რეჟიმები: **„რომელია მეტი?“** და **„რომელია ნაკლები?“**.
- ნიმუშში დაწყვილება და შემდეგ პასუხის მონიშვნა.
- „მე ვცდი“ რეჟიმში არეული საგნების დაჭერით დალაგება/დაწყვილება და შემდეგ პასუხის არჩევა.
- პრაქტიკაში დამხმარე ცხოველი პასუხამდე დამალულია; „მინიშნება“ აჩენს შესაბამის მიმართულებას.
- `npm run dev` ახლა ჯერ ავტომატურად ააგებს comparison მოდულს, შემდეგ გაუშვებს Vite-ს.
