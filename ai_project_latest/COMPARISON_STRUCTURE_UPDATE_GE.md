# შედარების მოდულის განახლებული სტრუქტურა

## 1. ვისწავლოთ შედარება
- კალათბურთისა და ფეხბურთის ბურთები.
- რაოდენობები კოდში არსებობს მხოლოდ ლოგიკისთვის; მოსწავლეს არ ეჩვენება არც რაოდენობის ციფრი და არც რაოდენობის ბეჯი.
- მოსწავლე თითო ბურთს მეორე ტიპის ბურთს უწყვილებს.
- დარჩენილი ბურთით ადგენს, რომელია მეტი.

## 2. ვისწავლოთ შედარება, დავითვალოთ
- ვაშლი — 4; მსხალი — 2.
- ჯერ ერთ-ერთზე დაწყვილება, შემდეგ რაოდენობების დათვლა/შედარება.
- მარჯვენა დამხმარე პანელში ჩანს ბეგემოტი.
- რაოდენობები ამ ეტაპზე უკვე აშკარად ჩანს.

## დამატებით
- მთავარი ნავიგაციის მეოთხე ველად შენარჩუნებულია `ბურთებით ვივარჯიშოთ` და იყენებს ძველ `ActivityFour` კომპონენტს.
- ზედა მარჯვენა რუბრიკაში ჩანს წიგნის გოგო/ბიჭის ილუსტრაცია და ტექსტი `ვისწავლოთ ერთად`.
- მობილურზე მარჯვენა დამხმარე პანელი ავტომატურად გადადის მთავარი აქტივობის ქვემოთ.
