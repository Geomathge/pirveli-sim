# თავდაპირველი აპლიკაცია — ჩაშენებული შედარებით

გახსენით მთავარი index.html. ეს არის თავდაპირველი „მოვემზადოთ მათემატიკისთვის“ აპლიკაცია. მენიუ და საწყისი გაკვეთილები შენარჩუნებულია. მეექვსე ღილაკი „დაწყვილება და შედარება“ ხსნის ახალ შედარების კომპონენტს თავისი სამი ქვე-რეჟიმით.

მზა კოდი: index.html, app.js, styles.css, assets და comparison.
გაშვება: ამ საქაღალდეში python3 -m http.server 8000; შემდეგ http://localhost:8000.

შედარების რედაქტირებადი React წყარო: comparison-source. ამ საქაღალდეში npm ci და npm run build აწყობს comparison-build-ს. აწყობილი ფაილები გადაიტანეთ მთავარ comparison საქაღალდეში. საწყისი აპლიკაცია აგებას არ საჭიროებს.

ეს ZIP მოიცავს მზა აწყობილ შედარებასაც. API გასაღები არ სჭირდება. საჯარო ვებგვერდზე ცვლილება ამ პაკეტის შექმნით არ გამოქვეყნებულა.
